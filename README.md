
# 🍔 Food Hub

Food Hub is a modern food ordering web application built with React, Vite, and Tailwind CSS. It provides a user-friendly interface for exploring food items and enjoying a convenient online food ordering experience.

## 🚀 Live Demo

https://shahariyar-18.github.io/food-hub/

## ✨ Features

- 🍕 Browse food items and explore the menu
- 🎨 Modern and responsive user interface
- 📱 Mobile-friendly design
- ⚡ Fast performance powered by Vite
- 💅 Stylish UI with Tailwind CSS
- ⚛️ Component-based architecture using React

## 🛠️ Technologies Used

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Language:** TypeScript / JavaScript
- **Deployment:** GitHub Pages
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Shahariyar-18/food-hub.git
```

### 2. Navigate to the project folder

```bash
cd food-hub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```
